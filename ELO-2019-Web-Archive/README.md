# ELO 2019 Web Archive — Peripheries

## Description
Web archive of the ELO 2019 conference site, *Peripheries*, held in Cork,
Ireland. The ELO Conference Archive index already links to a Wayback Machine
snapshot of the original site; this folder holds an independent ArchiveBox
capture (SingleFile snapshots for browsing/search, plus a full WARC/media
mirror for preservation) of that same snapshot, so it is searchable alongside
the other conference archives in this repository.

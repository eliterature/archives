# ELO 2010 Web Archive — ELO_AI: Archive & Innovate

## Description
Web archive of the ELO 2010 conference site, *ELO_AI: Archive & Innovate*,
held in Providence, Rhode Island. Captured from the original site at
https://www.brown.edu/Conference/Electronic_Literature_Organization/ using
ArchiveBox (SingleFile snapshots for browsing/search, plus a full WARC/media
mirror for preservation).

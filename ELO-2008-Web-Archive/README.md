# ELO 2008 Web Archive — Visionary Landscapes

## Description
Web archive of the ELO 2008 conference site, *Visionary Landscapes*, held in
Vancouver, Washington. Captured from the original site at
https://dtc-wsuv.org/elit/elo08/media.html using ArchiveBox (SingleFile
snapshots for browsing/search, plus a full WARC/media mirror for
preservation).

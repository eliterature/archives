# ELO 2023 Web Archive — Overcoming Divides

## Description
Web archive of the ELO 2023 conference site, *Overcoming Divides: Electronic
Literature and Social Change*, held in Coimbra, Portugal and online. Captured
from the original site at
https://ucpages.uc.pt/events/overcoming-divides-electronic-literature-and-social-change/
using ArchiveBox (SingleFile snapshots for browsing/search, plus a full
WARC/media mirror for preservation).

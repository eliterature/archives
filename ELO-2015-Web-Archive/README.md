# ELO 2015 Web Archive — The End(s) of Electronic Literature

## Description
Archive of the ELO 2015 conference proceedings, *The End(s) of Electronic
Literature*, held in Bergen, Norway. Unlike the other entries in this
repository, ELO 2015 has no standalone conference website — the ELO
Conference Archive index links directly to a PDF proceedings book, captured
here via ArchiveBox as-is (no site crawl).

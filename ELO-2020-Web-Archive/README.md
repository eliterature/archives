# ELO 2020 Web Archive — (un)continuity

## Description
Web archive of the ELO 2020 conference site, *(un)continuity*, held in
Orlando, Florida (Virtual). Captured from the original site at
https://elo.cah.ucf.edu/ using ArchiveBox (SingleFile snapshots for
browsing/search, plus a full WARC/media mirror for preservation).

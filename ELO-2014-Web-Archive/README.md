# ELO 2014 Web Archive — Hold the Light

## Description
Web archive of the ELO 2014 conference site, *Hold the Light*, held in
Milwaukie, Wisconsin. The original site is already hosted as a subpage of the
ELO Conference Archive (https://conference.eliterature.org/archive/2014/index.html);
this folder holds an independent ArchiveBox capture (SingleFile snapshots for
browsing/search, plus a full WARC/media mirror for preservation) so it is
searchable alongside the other conference archives in this repository.

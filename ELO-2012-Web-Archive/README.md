# ELO 2012 Web Archive — Electrifying Literature

## Description
Web archive of the ELO 2012 conference site, *Electrifying Literature:
Affordances and Constraints*, held in Morgantown, West Virginia. Captured
from the original site at https://el.eliterature.org/ using ArchiveBox
(SingleFile snapshots for browsing/search, plus a full WARC/media mirror for
preservation).

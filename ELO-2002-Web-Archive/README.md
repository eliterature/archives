# ELO 2002 Web Archive — State of the Arts Symposium

## Description
Web archive of the ELO 2002 conference site, *State of the Arts Symposium*,
held in Los Angeles, California. Captured from the original site at
https://www.eliterature.org/state/home.shtml using ArchiveBox (SingleFile
snapshots for browsing/search, plus a full WARC/media mirror for
preservation).

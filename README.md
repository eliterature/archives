## How to Contribute

Each archival project should have its own subfolder with a `README.md` that follows the template below.

To add a new project:

1. Create a new folder named after the project (e.g. `elc1`, `pathfinders`, `2007-conference-site`)
2. Include source files if available
3. Add a `README.md` with the following fields:

[template starts here...]

# Project Title

## Description
Brief summary of the project — what it is, what it does, why it matters to the field of electronic literature.

## Year of Origin
YYYY or range (e.g. 2006–2009)

## Contributors
- Name (Role)
- Name (Role)
- Include editors, developers, curators, artists, etc.

## Original Platform or Environment
List the software/hardware this work was originally designed for (e.g. Flash, Director, WordPress, Twine, Processing, etc.)

## Source Materials
List any included files or links:
- `/source/` folder includes original codebase or zipped website
- External links (Wayback Machine, artist’s website)
- Screenshots, video walkthroughs, etc.

## Licensing & Permissions
State what rights ELO has to archive this project.
- Public domain?
- Creative Commons?
- Used with permission from creator?

(If unknown, please note “Rights status unclear — needs review.”)

## Notes for Preservation
Optional. Add any known issues, quirks, bugs, or dependencies needed to run the work in its original state.

# ELO Archives

This repository hosts source code and archival materials from past Electronic Literature Organization projects, exhibitions, and publications.

## How to Contribute

Each archival project should have its own subfolder with a `README.md` that follows the template below.

To add a new project:

1. Create a new folder named after the project (e.g. `elc1`, `pathfinders`, `2007-conference-site`)
2. Include source files if available
3. Add a `README.md` with the following fields:

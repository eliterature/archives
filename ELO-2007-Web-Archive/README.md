# ELO 2007 Web Archive — The Future of Electronic Literature

## Description
Web archive of the ELO 2007 conference site, *The Future of Electronic
Literature*, held in College Park, Maryland. Captured from the original site
at https://archive.mith.umd.edu/elo2007/ using ArchiveBox (SingleFile
snapshots for browsing/search, plus a full WARC/media mirror for
preservation).
